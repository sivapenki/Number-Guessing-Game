# Number-Guessing-Game
A simple Python number guessing game using random numbers and loops.

## Features
- Random number generation
- User input handling
- Hint system (Too High / Too Low)
- Attempt counter
- Simple command-line interface

## Technologies Used
- Python
- Random Module
- Loops
- Conditional staments(if-elif-else)

## Sample Output
- Enter Guessing number: 30
  Too low..!!
- Enter Guessing number: 45
  Too High
- Enter Guessing number: 38
  Congrats You guessed in 3 Attempts
